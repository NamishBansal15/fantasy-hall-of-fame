# Fantasy Hall of Fame — ESPN 143378511

## Publish with GitHub Pages
1. Create a **public** GitHub repository named `fantasy-hall-of-fame`.
2. Upload `index.html` to the root of the repository and commit.
3. Open Settings > Pages. Under Build and deployment, select **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
4. Visit `https://YOUR-USERNAME.github.io/fantasy-hall-of-fame/` after deployment.

## Important: shared data
The current importer saves imported league data in each visitor's browser (localStorage). Importing data on your computer will **not** update what friends see. To publish real stats for everyone, the site needs a shared static data file (or backend) and a code update to load it. Until then visitors see demo data.
